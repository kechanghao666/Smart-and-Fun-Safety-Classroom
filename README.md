# 智趣安全学堂

一个面向学生的儿童安全教育互动学习系统。

系统以“主题学习 + 闯关游戏 + AI 助手 + 主题考试 + 结果反馈”为核心，首版重点实现“道路安全教育”主题，并提供学生端、教师端、管理员端三类使用入口。

---

## 当前状态

- 已完成远端仓库接入与多人协作基线
- 已完成前端工程骨架与页面联调基础
- 已完成后端工程、SQLite、鉴权、学生主链路、教师端/管理员端最小可联调接口
- 已完成 Spark 真实联机验收，AI 通过后端代理访问上游模型服务
- 当前正式协作基线为 `project-1.0`

---

## 核心范围

### 学生端

- 学生账号登录与角色识别
- 首次登录信息补充
- 首页主题卡片展示
- 道路安全教育主题学习
- 三关闯关式互动学习
- 学习进度自动记录与快捷续学
- AI 助手浮窗、提示和主题内问答
- 三关完成后自动解锁主题考试
- 错题查看与 AI 学习结果卡片

### 教师端

- 班级学习总览
- 学生完成情况查看
- 学生个体学习结果查看

### 管理员端

- 主题管理
- 关卡内容管理
- 题库管理
- AI 文案管理
- 用户管理与统计查看

## 快速开始

需要 Node.js 20+。

安装依赖并启动前端：

```bash
npm install
npm run dev
```

启动后端：

```bash
npm run dev:backend
```

构建：

```bash
npm run build
npm run build:backend
```

默认地址：

- 前端：`http://127.0.0.1:5173`
- 后端：`http://127.0.0.1:3001`

## 道路安全主题结构

### 第一关：城市交通观察员

在街道路口场景中识别红绿灯、斑马线、交通标志和危险行为，通过点击热点完成任务。

### 第二关：放学回家路线挑战

沿着放学回家路线逐步前进，在关键节点中做出安全选择。

### 第三关：安全出行守护任务

在公交车、私家车、电动车等场景中完成安全准备与危险行为纠正任务。

### 主题考试

三关全部完成后自动解锁，用于课后巩固与错题反馈。
