# `project-1.0` 协作实施计划（归档）

> 本文档用于归档项目早期在 `project-1.0` 分支上的协作方案。当前正式代码基线已收口到 `main`，启动、联调和验收请以 `README.md`、`docs/backend-frontend-handoff.md`、`docs/v1-contracts.md` 为准。

## 1. 项目目标与说明书约束

- 本项目以《功能设计说明书(1)》和《界面设计说明书(1)》作为唯一产品真源。
- 所有实现必须严格对齐说明书中的功能范围、页面结构、交互方式和角色职责，不允许为了赶进度擅自删减说明书条目。
- 当前仓库中的前端原型只作为工程起点和结构参考，不作为功能裁剪依据。
- 历史阶段曾以 `project-1.0` 为共同工作分支，以下内容保留为当时的实施记录。

## 2. 当前 owner 分工

### 前端负责人

- 项目发起人（当前协作人）负责前端实现。
- 负责范围：

  - AI 浮窗、独立 AI 问答页、AI 学习结果卡片页
  - 成长档案页与成长反馈相关页面
  - 教师端全部页面
  - 管理员端全部页面
  - 全局样式、通用组件、前端状态管理、接口接入与联调

### 后端负责人

- 协作同事负责后端实现。
- 负责范围：
  - 后端工程初始化
  - 三角色登录鉴权
  - 学生资料、学习进度、考试、错题、成长值、成长维度存储

  - 教师端数据接口
  - 管理员端主题、关卡、题库、AI 文案、用户、统计接口
  - SQLite 表结构、种子数据、接口文档

## 5. AI 模块接入原则

- AI 只围绕“道路安全教育”主题工作，不做开放搜索，不做跨主题复杂知识，不做深度情感陪伴对话。
- AI 保持单一固定角色，不做多角色切换。
- AI 浮窗与独立 AI 页均只支持主题内问答。
- 欢迎语、关卡提示、鼓励语、结果卡片文案优先使用后台可配置模板，保持稳定与可控。
- AI 密钥只允许放在后端环境变量中，不允许提交到仓库，不允许前端直连模型接口。
- 后端统一提供 AI 代理接口，前端只请求本项目后端。

## 6. 成长体系实现要求

- 默认提供 1 个儿童友好型虚拟人物形象，并与 AI 角色联动。
- 成长体系必须包含三类成长维度：
  - 形象外观
  - 安全能力
  - 专属场景
- 成长值来源必须覆盖：
  - 关卡通关
  - 主题考试
  - 错题重学
  - 连续学习
- 学生首页、主题详情页、AI 学习结果卡片页必须显示成长相关信息。
- 独立成长档案页必须展示成长值、升级进度、已解锁内容和成长记录。
- 教师端学生详情页必须显示学生成长状态。
- 管理员端数据统计必须预留成长数据展示能力。

## 7. 教师端与管理员端实现要求

### 教师端

- 教师首页采用后台式布局，展示班级学习总览、三关完成率、考试完成率、近期异常提醒。
- 班级学生列表页支持按班级、完成状态、考试状态进行筛选。
- 学生详情页展示关卡完成情况、考试成绩、错题概览、激励情况、成长状态和学习建议。

### 管理员端

- 管理员端采用标准管理系统布局：左侧菜单、顶部面包屑、右侧内容区。
- 主题管理页采用列表 + 编辑弹窗形式。
- 关卡内容管理页采用关卡列表 + 场景配置区双栏结构。
- 题库管理页采用题目列表 + 编辑面板形式。
- AI 文案管理页采用分类标签页 + 编辑预览区形式。
- 用户管理页采用标准表格布局，支持搜索和状态筛选。
- 数据统计页采用多卡片 + 简洁图表形式。

## 9. 提交与分支规范（历史记录）

- 当时的约定是 `main` 只接收评审通过的 PR，不直接开发。
- 当时的共同集成分支固定为 `project-1.0`。
- 当时前端负责人使用 `feature/frontend-*` 命名分支。
- 当时后端负责人使用 `feature/backend-*` 命名分支。
- 涉及共享类型、路由、状态模型、字段结构时，必须同步更新 `docs/` 下相关文档。
- 每次提交前至少自检：
  - 角色权限
  - 学习流程
  - 关卡解锁
  - 考试解锁
  - AI 提示
  - 成长状态

## 10. 验收标准

- README 中可以直接打开本实施计划文档。
- 文档中明确写明前端负责人和后端负责人。

- 学生端、教师端、管理员端实现内容与两份说明书保持一致。

## 11. 当前默认技术方案

- 前端：React + TypeScript + Vite
- 后端：Node.js + Express + SQLite
- AI 调用：后端代理模型服务，前端不直连
- 当前开放主题：道路安全教育
- 其他主题：首页保留占位卡片，并显示“正在开发，敬请期待”
